## Code blocker

### M33-B1 — refusal and admission use different equivalence rules

`src/app.py:59-73` includes trade names even when the question linker's `_OTHER_PRODUCT_NAMES` declares them a different product. `Engine.explore` at `src/app.py:139-150` first asks the linker to refuse the input, then admits a stored name through `_sig`. The latter ignores punctuation, spacing and trademark signs. The former depends on token windows and clause boundaries (`src/query.py:788-805,874-896`) and folds trademark signs differently (`src/query.py:117-118`). Thus an empty/non-refused linker result is not proof that the stored name is safe to draw.

All following pairs were independently reproduced over HTTP. Plain controls return `refused`; the variants return `center`:

| Plain, refused input | Exact variant drawn | Incorrect center |
|---|---|---|
| `Myocet` | `Myocet™`, `My/o/cet`, `My ocet` | `CHEMBL359744` — DOXORUBICIN HYDROCHLORIDE |
| `Inflectra` | `Inf/lectra` | `CHEMBL1201581` — INFLIXIMAB |
| `Equidacent` | `Equi/dacent` | `CHEMBL1201583` — BEVACIZUMAB |
| `Fyarro` | `Fy/arro` | `CHEMBL413` — SIROLIMUS |
| `Megace ES` | `Megace/ES` | `CHEMBL1201139` — MEGESTROL ACETATE |

For example, `_sig('Myocet') == _sig('Myocet™') == _sig('My/o/cet') == 'myocet'`. This is not an extra qualifier absent from the stored name. It is a **known refused product admitted through another path**, directly violating the refusal guarantee. `_OTHER_PRODUCT_NAMES` already records that these brands denote other products; no new external product interpretation is needed to establish the code inconsistency.

The systematic sweep covers **38 stored spellings × 12 forms = 456 cases**. **248 forms across 37 stored spellings draw a center**; 201 are refused and seven return an excluded-source reply. This is one failure family, not 248 separate blockers.
