## Causes

- **Isotope:** `canonical_key` deletes non-alphanumeric characters (`src/textrules.py:339-346`), but `_alnum_words` turns them into word boundaries (`src/query.py:111-113`). `_marked` then tests one- or two-word windows joined by a space (`src/query.py:250-265`). `89Z.r` becomes `89Z r`: `89Z` uses unrecognized element `Z`, while `89Z r` has a separator inside the element symbol, which `RE_ISOTOPE` does not accept (`src/textrules.py:289-298`). The alias key still recognizes `89zr-trastuzumab`. Raw bracket removal and exact parent lookup independently bypass refusal (`src/textrules.py:359-363`; `src/normalize.py:738-758`).
- **Suffix:** a standalone hyphen remains a raw token (`src/query.py:309-310`). Both positive lookup and `_drug_spans` cap windows at five raw tokens (`src/query.py:378-389,446-463`). The control's five-token alias reaches `_marked` and its canonical suffix check (`src/query.py:241-245`); the six-token attack cannot. Bare `bevacizumab` is then matched, and the adjacent check examines only the first normalized word `a`, not the suffix assembled from `a w w b` (`src/query.py:250-263`). The item guard's separator-to-space view still leaves four suffix letters separated, so its anchored suffix expression does not fire (`src/query.py:125-141`; `src/textrules.py:156-157,202-223`).

The evidence does not require an external pharmacological claim. `awwb` and `zr` are explicit project guard vocabulary (`src/textrules.py:169-171,290-298`), the exact controls are refused, and both attacks preserve the letters/digits and the stored lookup identity. Canonical-key equality alone would not justify arbitrary synonym equivalence; here it corroborates these specific punctuation/tokenization changes and the already recorded refusal semantics. No speculative language variants were considered.
