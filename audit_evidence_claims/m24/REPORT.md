## M24-B1 — payload-substring exemption admits an unmodified small molecule (P1)

**Exact input: `irinotecan conjugated to polyethylene glycol`.** The resolver yields `CONTAINED_ALIAS` for IRINOTECAN and `UNRESOLVED` residue, with no blocked component. `_resolver_blocked` is empty, `_qualified` is false, `_item_has_isotope` is false, `_marked` returns None, and the public linker emits CHEMBL481 without Refused. The original CLI server returns the complete bare-irinotecan map, including **five graph trials**, and **five trial / four sponsor QA evidence rows**. The page form draws IRINOTECAN and its CHEMBL481 trail. [Complete stages](attacks/new_results.json), [HTTP](checks/independent_m24_http.json), [full-response assertions](attacks/assertions.json), [page](contract/ui_m24_http.json).

**Causal hypothesis and evidence:** the new `_PAYLOAD` expression at `src/query.py:227-228` uses an unrestricted `search` for `tecan`, `dotin` and other fragments. `_marked` at `src/query.py:549-551` refuses a joined description only if that search fails. For this exact input, the outside-name `_item_joined` check is **True**, but the preferred name **IRINOTECAN** matches **TECAN**, so the guard is bypassed. The stored drug type is `Small molecule`; the name does not designate an antibody carrying a separate payload. The same causal path is observed for topotecan, rubitecan, belotecan and exatecan mesylate via `TECAN`, and tasidotin hydrochloride via `DOTIN`. The supporting variants are lexical tests, not claims that each described conjugate is an established product.

The controlled ablation temporarily replaces **only** `_PAYLOAD` with a never-match expression in one process. The irinotecan, topotecan and tasidotin modified descriptions then refuse; bare irinotecan and topotecan retain structurally identical map objects. The original expression is restored and no source file changes. This supports the exception as the cause rather than a separate resolver/data mismatch. [Ablation script](attacks/counterfactual.py), [results](attacks/counterfactual.json).

**Identity premise:** NCI defines etirinotecan pegol as an irinotecan–polyethylene-glycol conjugate with a linker that releases irinotecan. Thus an explicit PEG-conjugated irinotecan description is not bare irinotecan. The generic query does not specify the linker sufficiently to force a unique etirinotecan-pegol assignment; refusal is sufficient. This is an identity distinction, not a treatment or approval claim. [NCI Drug Dictionary](https://www.cancer.gov/publications/dictionaries/cancer-drug/def/etirinotecan-pegol).

**Paired controls:** `etirinotecan pegol` retains its own CHEMBL3039558 node. `paclitaxel conjugated to polyethylene glycol` and `doxorubicin conjugated to polyethylene glycol` refuse under the new guard. `pegylated irinotecan` and `irinotecan labelled with Ce-134` independently refuse. `trastuzumab deruxtecan antibody-drug conjugate` and the stored matched name `Paclitaxel conjugate with poly-l-glutamic acid` retain their intended distinct-product nodes. These controls establish that the failure is the exemption's identity test, not a requirement to reject all conjugate names.

Required repair: distinguish a payload-bearing product identity from a molecule whose own name merely contains the same suffix. Add paired plain-molecule/conjugate controls through linker, map and QA paths. The audit changes no application code.

## M24-B2 — explicit coupling and intervening-linker wording still draw the antibody (P1)

**Exact inputs: `trastuzumab coupled to IRDye800CW` and `trastuzumab linked via a linker to IRDye800CW`.** Both pass every refusal stage and produce the complete bare-trastuzumab map: **13 graph trials / 12 trial QA rows / 12 sponsor QA rows**. The actual form renders a TRASTUZUMAB SVG and CHEMBL1201585 trail. `IRDye800CW coupled to trastuzumab`, `trastuzumab coupled with IRDye800CW`, `trastuzumab chemically attached to IRDye800CW`, and the Herceptin alias corroborate this descriptor-coverage mechanism. [Stages](attacks/new_results.json), [HTTP](checks/independent_m24_http.json), [equality assertions](attacks/assertions.json), [page](contract/ui_m24_http.json).

**Cause:** `_JOINED` (`src/query.py:225`) lists conjugation/covalent stems; `_item_joined` recognizes `linked` only when the **immediately next word** is `to` or `with` (`src/query.py:241-243`). It does not recognize `coupled to`, and `linked via a linker to` misses that adjacency test. Both return `_item_joined=False`. The pre-existing distinct-product patterns also lack these explicit modification constructions (`src/textrules.py:139-152,202-212`); `_qualified` delegates to those predicates (`src/query.py:353-375`). Resolver residue is reported but not refused. The parent is emitted at `src/query.py:705-723`, and `Engine.explore` selects it at `src/app.py:88-95`.

**Identity premise:** Jeong et al. synthesize and isolate a trastuzumab–IRDye800CW imaging probe through click chemistry. Wang et al. independently describe attaching the dye to trastuzumab-based conjugates. These primary methods support the distinction between an explicitly dye-coupled antibody and the unmodified antibody. The exact audit wording is a reviewer paraphrase, not a purported published trade name. [Jeong et al., 2021](https://jgc-online.org/DOIx.php?id=10.5230/jgc.2021.21.e18), [Wang et al., 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4949282/). [Source notes and limits](attacks/sources.json).

Controls `trastuzumab conjugated to IRDye800CW`, `trastuzumab covalently coupled to IRDye800CW`, `trastuzumab chemically linked to IRDye800CW`, and `trastuzumab conjugated via a linker to IRDye800CW` all refuse. This groups synonymous coupling and intervening-linker descriptions as **one incomplete descriptor mechanism**, not a separate blocker for each wording. It does not classify the ambiguous `trastuzumab with IRDye800CW` co-occurrence as a blocker.
