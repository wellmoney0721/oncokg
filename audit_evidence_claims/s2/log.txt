## Process

1. Issue references in the commit messages (`#123`, `Closes #45`, GitLab `!67`, etc.) ??fetch via the workflow in `docs/agents/issue-tracker.md`.

### 3. Identify the standards sources

"""Structured answers: claims checked exactly against the graph, prose written from them.

Reading free prose for unsupported claims is a pattern match over sentence shapes,
and six adversarial rounds kept finding shapes it misread (see claims.py and README
known defect 13). This module removes the problem instead of chasing it: a language
model does not write the answer, it fills in claims, and the program writes the
answer from the claims that check out.

A claim is a small JSON object of a fixed kind with fixed keys:

  {"kind": "relation", "relation": "ACTS_ON", "subject": "osimertinib",
   "object": "EGFR", "evidence": "<edge id>", "action": "INHIBITOR"}          (action optional)
  {"kind": "relation", "relation": "EVALUATES", "subject": "NCT03909334",
   "object": "osimertinib", "evidence": "<edge id>"}
  {"kind": "relation", "relation": "SPONSORS_TRIAL_OF", "subject": "AstraZeneca",
   "object": "osimertinib", "evidence": "<edge id>", "trial_count": 14}       (trial_count optional)
  {"kind": "trial", "trial": "NCT03909334", "evidence": "<edge id>",
   "phase": ["PHASE2"], "status": "ACTIVE_NOT_RECRUITING"}                    (phase, status optional; one needed)
  {"kind": "drug", "drug": "osimertinib", "evidence": "<edge id>",
   "max_stage": "APPROVAL", "trials_in_graph": 118}                           (one of the two needed)

A claim is accepted only when all of these hold:

  * its kind and keys are exactly as above (an unknown key rejects the claim, so no
    free text can ride along) and every value has the expected type;
  * the cited evidence id is one of the edges retrieved for this question, and that
    edge is live in the graph (or, for a drug claim, it is the drug's own profile
    record "profile:<id>" retrieved for this question);
  * the edge's relation is the claimed relation, and its two ends are the entities
    the claim names (a name must resolve, as a whole, to exactly that node id);
  * every value equals what the graph stores: the edge's action type, the sponsor's
    trial count, the trial's phase set and status, the drug's maximum stage, and the
    number of live trials evaluating the drug.

The answer shown to the reader is written by `render` from accepted claims only, using
the graph's own labels and values, never the claim's strings. A claim that does not
check out is reported with the reason and left out of the answer.

What this does not do: it cannot tell whether the claims chosen answer the question
well, or whether something important was left out. It guarantees that what is said is
in the graph, not that everything in the graph that matters was said.
"""
from __future__ import annotations

import json
import re
import sqlite3

RELATIONS = {"ACTS_ON": ("Drug", "Target"), "EVALUATES": ("Trial", "Drug"),
             "SPONSORS_TRIAL_OF": ("Company", "Drug")}
KEYS = {
    "relation": ({"kind", "relation", "subject", "object", "evidence"},
                 {"action", "trial_count"}),
    "trial": ({"kind", "trial", "evidence"}, {"phase", "status"}),
    "drug": ({"kind", "drug", "evidence"}, {"max_stage", "trials_in_graph"}),
}
RE_NCT = re.compile(r"NCT\d{8}")


def _norm(v: str) -> str:
    """Spelling-insensitive form of a stored code: "phase 2" = "PHASE2" = "Phase-2"."""
    return re.sub(r"[\s\-_/]+", "", v.strip().upper())


def _flat(s: str) -> str:
    """Case and punctuation aside, the same characters: letters of any script count, so
    "osimertinib가 아닌" is not the same name as "osimertinib"."""
    return " ".join(re.findall(r"[^\W_]+", s.casefold()))


def _no_constant(name):
    raise ValueError(f"{name} is not a JSON number")


class Verifier:
    def __init__(self, kg):
        self.kg = kg

    # -- entity names --------------------------------------------------------- #
    def resolve(self, name, want: str) -> tuple[set[str], str | None]:
        """Node ids a name stands for, as a whole, among nodes of type `want`."""
        if not isinstance(name, str) or not name.strip() or len(name) > 120:
            return set(), "the name must be a short non-empty string"
        name = name.strip()
        row = self.kg.conn.execute("SELECT id, type FROM node WHERE id=? AND retired_at IS NULL",
                                   (name,)).fetchone()
        if row:
            return ({row["id"]}, None) if row["type"] == want else (
                set(), f"{name} is a {row['type'].lower()}, not a {want.lower()}")
        if want == "Trial":
            return set(), "a trial is named by its registry id (NCT followed by 8 digits)"
        # a label exactly as the graph (and so the evidence) writes it
        rows = self.kg.conn.execute(
            "SELECT id, type FROM node WHERE lower(label)=lower(?) AND retired_at IS NULL",
            (name,)).fetchall()
        if rows:
            ids = {r["id"] for r in rows if r["type"] == want}
            if ids:
                return ids, None
            return set(), f"{name} is a {rows[0]['type'].lower()}, not a {want.lower()}"
        if not (name.isascii() and name.isprintable()):
            # the linker drops characters it cannot read, so "osimertinib是安全的" would
            # pass as osimertinib; outside the graph's own labels, names are plain ASCII
            return set(), (f"'{name}' is not written the way the graph writes names "
                           "(use the id or the name as it appears in the evidence)")
        ents = [e for e in self.kg.link_entities(name) if e.get("type") not in ("Disease",)]
        whole = len(ents) == 1 and _flat(ents[0].get("matched_text") or "") == _flat(name)
        if whole and ents[0].get("type") != want:
            return set(), f"{name} is a {ents[0]['type'].lower()}, not a {want.lower()}"
        if not whole:
            return set(), f"'{name}' does not name exactly one {want.lower()} on its own"
        e = ents[0]
        return {e["id"], *e.get("also_matching_ids", [])}, None

    # -- one claim ------------------------------------------------------------ #
    def check(self, claim, retrieved: set[str]) -> tuple[dict | None, str | None]:
        """Return (facts to render, None) or (None, reason)."""
        if not isinstance(claim, dict):
            return None, "a claim must be a JSON object"
        kind = claim.get("kind")
        if not isinstance(kind, str) or kind not in KEYS:
            return None, f"unknown kind {kind!r}; use relation, trial or drug"
        need, may = KEYS[kind]
        keys = set(claim)
        if need - keys:
            return None, f"missing {sorted(need - keys)}"
        if keys - need - may:
            return None, f"unknown keys {sorted(keys - need - may)} (no free text is accepted)"
        ev = claim["evidence"]
        if not isinstance(ev, str) or ev not in retrieved:
            return None, "the cited evidence is not among the edges retrieved for this question"
        edge = self.kg.conn.execute(
            "SELECT * FROM edge WHERE id=? AND retired_at IS NULL", (ev,)).fetchone()
        if kind == "drug" and edge is None and ev.startswith("profile:"):
            edge = {"id": ev, "rel": "PROFILE", "src": ev.split(":", 1)[1], "dst": None,
                    "props": "{}"}
        if edge is None:
            return None, "the cited evidence is not a live edge of the graph"
        return getattr(self, "_" + kind)(claim, edge)

    def _relation(self, c, edge):
        rel = c["relation"]
        if not isinstance(rel, str) or rel not in RELATIONS:
            return None, f"unknown relation {rel!r}"
        if edge["rel"] != rel:
            return None, f"the cited edge is {edge['rel']}, not {rel}"
        st, ot = RELATIONS[rel]
        s_ids, why = self.resolve(c["subject"], st)
        if why:
            return None, why
        o_ids, why = self.resolve(c["object"], ot)
        if why:
            return None, why
        if edge["src"] not in s_ids or edge["dst"] not in o_ids:
            return None, "the cited edge does not join these two entities in this direction"
        props = json.loads(edge["props"] or "{}")
        facts = {"kind": "relation", "relation": rel, "edge": edge["id"],
                 "subject": edge["src"], "object": edge["dst"]}
        if "action" in c:
            if rel != "ACTS_ON" or not isinstance(c["action"], str):
                return None, "an action belongs to an ACTS_ON claim, as a string"
            if _norm(c["action"]) != _norm(props.get("action_type") or ""):
                return None, (f"the graph gives the action as {props.get('action_type') or 'none'}, "
                              f"not {c['action']}")
            facts["action"] = props["action_type"]
        if "trial_count" in c:
            n = c["trial_count"]
            if rel != "SPONSORS_TRIAL_OF" or type(n) is not int:
                return None, "a trial_count belongs to a SPONSORS_TRIAL_OF claim, as a whole number"
            if n != props.get("evidence_trials"):
                return None, f"the graph gives {props.get('evidence_trials')} trials, not {n}"
            facts["trial_count"] = n
        return facts, None

    def _trial(self, c, edge):
        if edge["rel"] != "EVALUATES":
            return None, "a trial's phase or status is cited from an EVALUATES edge of that trial"
        ids, why = self.resolve(c["trial"], "Trial")
        if why:
            return None, why
        if edge["src"] not in ids:
            return None, "the cited edge belongs to a different trial"
        if "phase" not in c and "status" not in c:
            return None, "a trial claim states a phase, a status or both"
        node = self.kg.conn.execute("SELECT props FROM node WHERE id=?", (edge["src"],)).fetchone()
        props = json.loads(node["props"] or "{}")
        facts = {"kind": "trial", "edge": edge["id"], "trial": edge["src"]}
        if "phase" in c:
            ph = c["phase"]
            if not isinstance(ph, list) or not all(isinstance(x, str) for x in ph):
                return None, "phase is a list of strings, e.g. [\"PHASE2\"]"
            if sorted(_norm(x) for x in ph) != sorted(_norm(x) for x in props.get("phases") or []):
                return None, f"the graph gives the phase as {props.get('phases')}, not {ph}"
            facts["phase"] = props.get("phases")
        if "status" in c:
            if not isinstance(c["status"], str) or _norm(c["status"]) != _norm(props.get("status") or ""):
                return None, f"the graph gives the status as {props.get('status')}, not {c['status']}"
            facts["status"] = props.get("status")
        return facts, None

    def _drug(self, c, edge):
        ids, why = self.resolve(c["drug"], "Drug")
        if why:
            return None, why
        if edge["rel"] not in ("ACTS_ON", "PROFILE") or edge["src"] not in ids:
            return None, "a drug's stage or trial count is cited from that drug's own statement"
        if "max_stage" not in c and "trials_in_graph" not in c:
            return None, "a drug claim states max_stage, trials_in_graph or both"
        node = self.kg.conn.execute("SELECT props FROM node WHERE id=?", (edge["src"],)).fetchone()
        props = json.loads(node["props"] or "{}")
        facts = {"kind": "drug", "edge": edge["id"], "drug": edge["src"]}
        if "max_stage" in c:
            if not isinstance(c["max_stage"], str) or \
                    _norm(c["max_stage"]) != _norm(props.get("max_phase_overall") or ""):
                return None, (f"the graph gives the maximum stage as "
                              f"{props.get('max_phase_overall')}, not {c['max_stage']}")
            facts["max_stage"] = props.get("max_phase_overall")
        if "trials_in_graph" in c:
            n = c["trials_in_graph"]
            real = self.kg.conn.execute(
                "SELECT COUNT(*) FROM edge WHERE rel='EVALUATES' AND dst=? AND retired_at IS NULL",
                (edge["src"],)).fetchone()[0]
            if type(n) is not int or n != real:
                return None, f"the graph gives {real} trials evaluating this drug, not {n}"
            facts["trials_in_graph"] = real
        return facts, None

    # -- a whole answer -------------------------------------------------------- #
    def verify(self, payload, evidence) -> dict:
        """`payload` is the model's JSON (a string or already parsed)."""
        if isinstance(payload, str):
            try:
                # NaN and Infinity are not JSON; refusing them keeps every echo valid JSON
                payload = json.loads(payload, parse_constant=_no_constant)
            except (ValueError, RecursionError) as e:
                return {"verified": False, "accepted": [], "text": "",
                        "rejected": [{"claim": None, "why": "not valid JSON: "
                                      + (getattr(e, "msg", None) or "nested too deeply")}]}
        claims = payload.get("claims") if isinstance(payload, dict) else None
        if isinstance(claims, list) and not claims and set(payload) == {"claims"}:
            # the model's way of saying the evidence does not answer the question
            return {"verified": False, "accepted": [], "rejected": [], "text": "",
                    "empty": True}
        if not isinstance(claims, list) or set(payload) != {"claims"}:
            return {"verified": False, "accepted": [], "text": "",
                    "rejected": [{"claim": None,
                                  "why": 'the answer must be {"claims": [...]} and nothing else'}]}
        retrieved = {e.edge_id for e in evidence}
        accepted, rejected = [], []
        for c in claims[:50]:
            try:
                facts, why = self.check(c, retrieved)
            except Exception as e:           # a claim the checker cannot read is rejected
                facts, why = None, f"the claim could not be read ({type(e).__name__})"
            if why:
                rejected.append({"claim": c, "why": why})
            else:
                accepted.append(facts)
        if len(claims) > 50:
            rejected.append({"claim": None, "why": "more than 50 claims; the rest were not read"})
        return {"verified": not rejected, "accepted": accepted, "rejected": rejected,
                "text": render(accepted, self.kg.conn)}


def render(facts: list[dict], conn: sqlite3.Connection) -> str:
    """Sentences from accepted facts, in the graph's own words."""
    def label(i):
        r = conn.execute("SELECT label FROM node WHERE id=?", (i,)).fetchone()
        return r[0] if r else i

    lines = []
    for f in facts:
        if f["kind"] == "relation" and f["relation"] == "ACTS_ON":
            act = f" ({f['action'].lower()})" if f.get("action") else ""
            lines.append(f"{label(f['subject'])} acts on {label(f['object'])}{act}")
        elif f["kind"] == "relation" and f["relation"] == "EVALUATES":
            lines.append(f"{label(f['subject'])} evaluates {label(f['object'])}")
        elif f["kind"] == "relation":
            n = f" {f['trial_count']}" if "trial_count" in f else ""
            lines.append(f"{label(f['subject'])} is lead sponsor of{n} trial(s) evaluating "
                         f"{label(f['object'])} - a sponsorship, not evidence of developing "
                         "the drug")
        elif f["kind"] == "trial":
            bits = []
            if "phase" in f:
                bits.append("phase " + ", ".join(f["phase"]) if f["phase"] else "no phase given")
            if "status" in f:
                bits.append("status " + f["status"])
            lines.append(f"{label(f['trial'])}: " + "; ".join(bits))
        else:
            bits = []
            if "max_stage" in f:
                bits.append(f"maximum clinical stage {f['max_stage']}")
            if "trials_in_graph" in f:
                bits.append(f"{f['trials_in_graph']} NSCLC trial(s) in this graph")
            lines.append(f"{label(f['drug'])}: " + "; ".join(bits))
        lines[-1] += f" [{f['edge']}]"
    return "\n".join(f"- {x}" for x in lines)

def render(facts: list[dict], conn: sqlite3.Connection) -> str:
    """Sentences from accepted facts, in the graph's own words."""
    def label(i):
        r = conn.execute("SELECT label FROM node WHERE id=?", (i,)).fetchone()
        return r[0] if r else i

    lines = []
    for f in facts:
        if f["kind"] == "relation" and f["relation"] == "ACTS_ON":

            lines.append(f"{label(f['subject'])} acts on {label(f['object'])}{act}")

            lines.append(f"{label(f['subject'])} evaluates {label(f['object'])}")
        elif f["kind"] == "relation":
            n = f" {f['trial_count']}" if "trial_count" in f else ""
            lines.append(f"{label(f['subject'])} is lead sponsor of{n} trial(s) evaluating "
                         f"{label(f['object'])} - a sponsorship, not evidence of developing "
                         "the drug")
        elif f["kind"] == "trial":
            bits = []
            if "phase" in f:
                bits.append("phase " + ", ".join(f["phase"]) if f["phase"] else "no phase given")
            if "status" in f:
                bits.append("status " + f["status"])
            lines.append(f"{label(f['trial'])}: " + "; ".join(bits))
        else:
            bits = []
            if "max_stage" in f:

            lines.append(f"{label(f['drug'])}: " + "; ".join(bits))

    def __init__(self, db_path: Path = DB_PATH,
                 resolved_path: Path = C.PROCESSED / "resolved.json"):
        self.conn = sqlite3.connect(db_path)
        self.conn.row_factory = sqlite3.Row
        resolved = json.loads(resolved_path.read_text(encoding="utf-8"))
        self.dic = resolved["dictionary"]
        self.index_keys = list(self.dic["index"].keys())
        self.disease = resolved["disease"]

                        if t.get("symbol")}
        # one name can denote several organisations (a group and a subsidiary
        # renamed after it), so a key maps to every matching node, not one.
        self.companies: dict[str, list[str]] = {}
        for row in self.conn.execute(
                "SELECT id,label FROM node WHERE type='Company' AND retired_at IS NULL"):
            self.companies.setdefault(T.canonical_key(row["label"]), []).append(row["id"])
            self.companies.setdefault(row["id"].removeprefix("ORG:"), []).append(row["id"])
        # a former name ("BeiGene") must still find the merged node
        for old, same in N.CURATED_SAME_ENTITY.items():
            if same in self.companies:
                self.companies.setdefault(old, []).extend(self.companies[same])
        self.companies = {k: sorted(set(v)) for k, v in self.companies.items()}

    # -- entity linking ---------------------------------------------------- #
    def link_entities(self, question: str) -> list[dict]:
        found: list[dict] = []
        seen: set = set()
        tokens = [t.strip(" ?.,!;:") for t in re.split(r"[\s,]+", question)
                  if t.strip(" ?.,!;:")]

        # The resolver's refusals apply to questions too. Linking straight
        # against the index let "Mvasi" or "liposomal doxorubicin" answer as
        # the originator molecule. A token naming a distinct product is
        # refused; a qualifier ("liposomal", "biosimilar") takes its
        # neighbours with it.
        refused: set[int] = set()
        for i, tok in enumerate(tokens):
            if T.is_distinct_product(tok) or T.is_radiotracer(tok):
                refused.add(i)
                if not T.canonical_key(tok) in self.dic["index"]:
                    refused.update({i - 1, i + 1})
        refused = {x for x in refused if 0 <= x < len(tokens)}
        run: list[int] = []
        for i in sorted(refused) + [None]:
            if run and (i is None or i != run[-1] + 1):
                span = " ".join(tokens[run[0]:run[-1] + 1])
                found.append({"type": "Refused", "id": None, "label": span,
                              "matched_text": span,
                              "why": "names a distinct product or tracer, not "
                                     "the originator molecule"})
                run = []
            if i is not None:
                run.append(i)

        for size in range(min(5, len(tokens)), 0, -1):
            for i in range(len(tokens) - size + 1):
                if refused & set(range(i, i + size)):
                    continue
                window = " ".join(tokens[i:i + size])
                if len(window) < 3:
                    continue
                key = T.canonical_key(window)

                hits = self.dic["index"].get(key)
                # Several words only make a drug name when the name itself has
                # several words. The key drops spaces, so "is a" read as the
                # abbreviation "isa" (isatuximab) in any question or answer.
                if hits and size > 1 and not re.search(r"[\s\-/]", hits[0]["alias"]):
                    hits = None
                if hits and len({h["drug_id"] for h in hits}) == 1:
                    did = hits[0]["drug_id"]
                    if ("Drug", did) not in seen:
                        seen.add(("Drug", did))
                        found.append({"type": "Drug", "id": did,
                                      "label": self.dic["drugs"][did]["name"],
                                      "matched_text": window,
                                      "matched_alias": hits[0]["alias"]})
                    continue

                if window.lower() in self.targets:
                    t = self.targets[window.lower()]
                    if ("Target", t["target_id"]) not in seen:
                        seen.add(("Target", t["target_id"]))
                        found.append({"type": "Target", "id": t["target_id"],
                                      "label": t["symbol"], "matched_text": window})
                    continue

                if key in self.companies:
                    cid = self.companies[key][0]
                    if ("Company", cid) not in seen:
                        seen.add(("Company", cid))
                        row = self.conn.execute(
                            "SELECT label FROM node WHERE id=?", (cid,)).fetchone()
                        found.append({"type": "Company", "id": cid,
                                      "label": row["label"], "matched_text": window,
                                      "also_matching_ids": self.companies[key][1:]})
                    continue

                if key in self.disease["index"]:
                    if ("Disease", self.disease["disease_id"]) not in seen:
                        seen.add(("Disease", self.disease["disease_id"]))
                        found.append({"type": "Disease",
                                      "id": self.disease["disease_id"],
                                      "label": self.disease["name"],
                                      "matched_text": window})
        return found

    def org_family(self, company_id: str) -> list[str]:
        """The organisation plus any companies a curated parent edge links to it."""
        ids = {company_id}

                "SELECT dst FROM edge WHERE rel='PARENT_OF' AND src=?"
                " AND retired_at IS NULL", (company_id,)):
            ids.add(row["dst"])
        return sorted(ids)

    # -- answering --------------------------------------------------------- #
    def answer(self, question: str, use_llm: bool | None = None) -> Answer:
        entities = self.link_entities(question)
        intent = self.classify(question, entities)
        evidence = self.retrieve(intent, entities)

        if intent == "unsupported" or not evidence:
            text = ("This graph cannot answer that. It covers companies, drugs, "
                    "targets and trials in non-small cell lung cancer only, and "
                    "it answers questions about which of those relate to which. "
                    "No entity in the question matched the graph."
                    if not entities else
                    "The entities in the question were recognised but the graph "
                    "holds no edges that answer it.")
            return Answer(question, intent, entities, text, [],
                          "refusal (no supporting evidence)",
                          {"grounded": True, "unsupported_claims": [],
                           "note": "refusing is the correct output when evidence is absent"})

        if use_llm is None:
            use_llm = bool(os.environ.get("ANTHROPIC_API_KEY"))
        if use_llm:
            # The model does not write the answer. It returns claims, each citing an
            # edge; the claims are checked exactly against the graph and the answer is
            # written from the accepted ones (structured.py).
            raw, by = self._llm_claims(question, evidence)
            result = self.verify_structured(raw, evidence)
            text = result["text"] or (
                "The model found nothing in the evidence that answers this question."
                if result.get("empty") else "None of the model's claims could be verified.")
            if result["rejected"]:
                text += (f"\n\n({len(result['rejected'])} claim(s) were removed because "
                         "the graph does not support them.)")
            checks = {"grounded": result["verified"], "applicable": True,
                      "method": "structured claims checked edge by edge against the graph",
                      "accepted": len(result["accepted"]), "rejected": result["rejected"],
                      "unsupported_claims": [{"kind": "rejected_claim", "value":
                                              json.dumps(r["claim"])[:120], "why": r["why"]}
                                             for r in result["rejected"]]}
            return Answer(question, intent, entities, text, evidence, by, checks)

        text, by = self._template_answer(question, intent, entities, evidence)
        # the trailing scope line is generated metadata, not a claim about the
        # world, so it is excluded from the groundedness check
        claim_text = text.split("\nScope:")[0]
        checks = self.check_groundedness(claim_text, evidence, entities,
                                         generated=False,
                                         vocabulary=set(self.dic["index"]),
                                         linker=self.link_entities)
        return Answer(question, intent, entities, text, evidence, by, checks)

    def verify_structured(self, payload, evidence) -> dict:
        """Check a structured answer against this question's evidence (structured.py)."""
        from structured import Verifier

"""A local page for trying the pipeline by hand.

    python src/app.py            then open http://localhost:8765

Four boxes: type an intervention string the way a registry would write it and see
how the resolver reads it, or ask a question and see the grounded answer with its
evidence, give a structured answer (claims citing evidence edges) and see which
claims the graph supports and the answer written from them, or paste free prose and
see what the auxiliary word-order check flags. All three call
the functions the pipeline uses (resolve_drug_string, OncoKG.answer,
OncoKG.check_groundedness) on the built artefacts, so what the page shows is what the
pipeline would do. Nothing is written; the language model is never called.
"""
from __future__ import annotations

import json
import sqlite3
import sys
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import config as C
import normalize as N
from query import OncoKG

PAGE = C.WEB / "try.html"
PORT = 8765


class Engine:
    def __init__(self):
        self.kg = OncoKG()
        # A browser opens spare connections it may never use, which would stall a
        # single-threaded server; requests are threaded, the engine is not.
        self.kg.conn.close()
        self.kg.conn = sqlite3.connect(C.PROCESSED / "oncokg.sqlite", check_same_thread=False)
        self.kg.conn.row_factory = sqlite3.Row
        self.lock = threading.Lock()
        self.dic = self.kg.dic
        self.index_keys = self.kg.index_keys
        target_rows, _, _ = N._load("targets")
        self.target_keys = N.target_guard_keys(target_rows, self.dic)

    def resolve(self, text: str) -> dict:
        out = N.resolve_drug_string(text, self.dic, self.index_keys, self.target_keys)
        for c in out["components"]:
            d = self.dic["drugs"].get(c.get("drug_id") or "")
            if d:
                c["drug"] = {k: d.get(k) for k in
                             ("name", "drug_type", "max_phase_overall", "max_phase_in_nsclc")}
                c["drug"]["mechanisms"] = [m.get("mechanismOfAction") if isinstance(m, dict) else m
                                           for m in (d.get("mechanisms") or [])][:3]
                c["drug"]["trials"] = self.kg.conn.execute(
                    "SELECT COUNT(*) FROM edge WHERE rel='EVALUATES' AND dst=? AND retired_at IS NULL",
                    (d["drug_id"],)).fetchone()[0]
                par = self.dic["drugs"].get(d.get("parent_molecule") or "")
                if par:
                    c["drug"]["parent"] = {"name": par["name"], "trials": self.kg.conn.execute(
                        "SELECT COUNT(*) FROM edge WHERE rel='EVALUATES' AND dst=? AND retired_at IS NULL",
                        (par["drug_id"],)).fetchone()[0]}
            if c.get("candidates"):
                c["candidate_names"] = [
                    (self.dic["drugs"].get(x) or {}).get("name", x) for x in c["candidates"]]
        return out

    def ask(self, question: str) -> dict:
        return self.kg.answer(question, use_llm=False).to_dict()

    def structured(self, question: str, payload: str) -> dict:
        """Check a structured answer (claims citing edges) and write the answer from it."""
        kg = self.kg
        entities = kg.link_entities(question)
        evidence = kg.retrieve(kg.classify(question, entities), entities)
        res = kg.verify_structured(payload, evidence)
        res["evidence"] = [{"edge_id": e.edge_id, "statement": e.statement} for e in evidence]
        return res

    def check(self, question: str, answer: str) -> dict:
        """Check an answer someone else wrote against the evidence for the question."""
        kg = self.kg
        entities = kg.link_entities(question)
        intent = kg.classify(question, entities)
        evidence = kg.retrieve(intent, entities)
        checks = kg.check_groundedness(answer, evidence, entities, generated=True,
                                       vocabulary=set(self.dic["index"]),
                                       linker=kg.link_entities)
        return {"intent": intent, "entities": entities, "checks": checks,
                "evidence": [{"statement": e.statement, "source_record": e.source_record,
                              "source": e.source, "url": e.url} for e in evidence[:8]],
                "evidence_count": len(evidence)}


def make_handler(engine: Engine):
    class Handler(BaseHTTPRequestHandler):
        def _send(self, code: int, body: bytes, ctype: str):
            self.send_response(code)
            self.send_header("Content-Type", ctype)
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def do_GET(self):
            if self.path in ("/", "/index.html"):
                self._send(200, PAGE.read_bytes(), "text/html; charset=utf-8")
            else:
                self._send(404, b"not found", "text/plain")

        def do_POST(self):
            try:
                n = int(self.headers.get("Content-Length") or 0)
                body = json.loads(self.rfile.read(min(n, 20000)) or b"{}")
                text = str(body.get("text") or "").strip()[:500]
                if not text:
                    raise ValueError("empty input")
                if self.path not in ("/api/resolve", "/api/ask", "/api/check",
                                     "/api/structured"):
                    return self._send(404, b"{}", "application/json")
                with engine.lock:
                    if self.path == "/api/resolve":
                        res = engine.resolve(text)
                    elif self.path == "/api/ask":
                        res = engine.ask(text)
                    elif self.path == "/api/structured":
                        answer = str(body.get("answer") or "").strip()[:20000]
                        if not answer:
                            raise ValueError("empty answer")
                        res = engine.structured(text, answer)
                    else:
                        answer = str(body.get("answer") or "").strip()[:4000]
                        if not answer:
                            raise ValueError("empty answer")
                        res = engine.check(text, answer)
                self._send(200, json.dumps(res, ensure_ascii=False,
                                           allow_nan=False).encode("utf-8"),
                           "application/json; charset=utf-8")
            except Exception as e:  # show the reason on the page, not a dead request
                self._send(400, json.dumps({"error": str(e)}, ensure_ascii=False).encode("utf-8"),
                           "application/json; charset=utf-8")

        def log_message(self, *a):
            pass
    return Handler


def main() -> None:
    port = int(sys.argv[1]) if len(sys.argv) > 1 else PORT
    engine = Engine()
    print(f"OncoKG try-it page: http://localhost:{port}", flush=True)
    ThreadingHTTPServer(("127.0.0.1", port), make_handler(engine)).serve_forever()


if __name__ == "__main__":
    main()

Each claim is accepted only if its keys are exactly those of its kind (no free-text
field exists, and an unknown key rejects the claim), the cited edge is one of those
retrieved for the question and is live (a drug claim may also cite the drug's
profile record retrieved for the question), the edge's relation and both ends are the
ones the claim names (a name is an id, a label exactly as the graph writes it, or an
alias that resolves, whole, to that node), and every value
equals what the graph stores: action type, sponsor's trial count, a trial's phase
set and status, a drug's maximum stage and its number of trials. The answer is then
written from accepted claims in the graph's own labels and values, with the edge id
after each line, so nothing the model typed reaches the reader. Rejected claims are
listed with the reason and left out.

This replaced checking the model's prose. Six adversarial rounds against a prose
checker (`src/claims.py`, kept as an auxiliary screen) each found new sentence
shapes that slipped through, because a reader of word order cannot keep up with
English. A closed claim format can be checked exactly. What it cannot judge is
whether the claims chosen answer the question well or leave something important
out: it guarantees what is said is in the graph, not that everything that matters
was said.

With no key, the evidence is rendered directly by a template, and the prose check
reports `applicable: false`, because a template built from the evidence cannot
fail a test against it. The pipeline has no required dependency on a model.
